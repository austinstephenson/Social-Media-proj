## Dylan's guide on how to run the frontend

1. Make sure you have Node.js installed and a `npm` version >= 20.
2. Open terminal.
3. `cd frontend` (Or just make sure your in the `frontend` folder)
4. `npm install` (Should say found 0 vulnerabilities)
5. `npm run dev`
6. Click the link to the locally hosted site that it gives you (should be something like http://localhost:5000/ but probably with different numbers)
